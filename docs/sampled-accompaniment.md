# 鋼琴、原聲貝斯、木吉他與柔和伴奏

2026-10-22：取代和弦／貝斯的純正弦波發聲，導奏亦改為鋼琴。網站沿用原有排程器、移調、速度與小節循環，目前固定使用柔和伴奏，不提供編排切換。

## 試聽方式

1. 開啟 http://127.0.0.1:5001 ，按 Ctrl+Shift+R 更新。
2. 選擇「奇異恩典」，預設為「柔和伴奏」。第一次播放先載入約 4.6 MB 本機音色，載入完成才開始預備拍，不會先漏掉歌曲首音。
3. 展開「奇異恩典：修改前後試聽」，可比較約 21 秒的純伴奏。兩份示範皆以 -20 LUFS 為目標做響度處理，避免音量差異主導比較；這項處理僅用於示範檔，不會改變即時播放輸出。
4. 播放固定使用柔和伴奏；各聲部可獨立調整音量、靜音或獨奏。
5. 要只聽伴奏，可將旋律導奏與節拍器靜音。比較播放器與練習播放會互相停止，避免重疊。

## 音色

- 從本機 FluidR3 GM（Frank Wen，MIT）離線製作：34 份鋼琴取樣（MIDI 42–90，每小三度一個錨點，兩個力度層），10 份原聲貝斯取樣（MIDI 28–55，每小三度一個錨點），26 份尼龍弦木吉他取樣（MIDI 45–81，兩個力度層）。
- 音色隨專案放在 `static/audio/instruments/`，不需要 CDN、MuseScore、SoundFont 播放外掛或線上服務。瀏覽器使用 MP3 解碼及 AudioBufferSourceNode 播放，選擇鄰近音高與力度層。
- 音色整體逐樂器正規化，保留力度層間的音量差異；鋼琴及貝斯原生取樣包含起音、泛音和衰減，不再將每個音維持成等音量長鳴。
- 琴鍵放開時約 200ms 收音，貝斯約 90ms、吉他約 160ms；和弦以最多數十毫秒的輕微展開柔化起音，節拍錨點不隨機移動。
- 分別加入高／低通濾波、輕微聲像分離、低比例短殘響與共用動態壓縮，保留主輸出餘裕。貝斯的殘響送出比例很低，避免低頻混濁。
- 停止、暫停、換曲會取消已排音符並清除殘響；音量、靜音及獨奏透過音軌匯流排立即作用於正在發聲的音符。
- 音色清單或個別檔案缺失時明確顯示錯誤，可重試播放，不會悄悄退回舊的電子音。
- 授權與貢獻者名單見 `static/audio/instruments/LICENSE.txt`；manifest 記錄來源 SoundFont 與各檔案 SHA256。

重建音色（開發用，正常播放不需要）：

```bash
python3 tools/build_instrument_samples.py /path/to/FluidR3_GM.sf2
```

重建需 libfluidsynth 與 ffmpeg。腳本以 ctypes 離線渲染，不啟動音效裝置。FluidSynth 本身未隨網頁發佈，僅輸出樂器取樣。

## 編排

`static/js/accompaniment.js` 在播放時製作新的音軌物件，不覆寫歌曲 JSON、旋律、原有和弦代號或來源 MusicXML。

- 3/4：每小節第一拍短根音貝斯，第二拍輕鋼琴和弦、第三拍更輕。弱起與中途和弦變換不會倒填到之前拍位。
- 4/4 等四分音符拍號慢歌：疏落四分音符分解和弦，加根音／五度貝斯。
- 鋼琴採 MIDI 54–78 範圍的緊密轉位，以較小的聲部移動連接，與低音分開。
- 旋律前的空白、整段無旋律的小節不填伴奏；樂句後的休止減少尾音，每四小節輕微減弱，最後一小節改以收束和弦。
- 木吉他預設音量 25%，以半拍錯開的輕柔撥弦填補鋼琴拍點之間的空間，末小節輕刷收束；不增加低音，避開開頭空白、整小節休止與已知句尾留白。可獨立調音量、靜音或獨奏。
- 《柯南》保留原有鋼琴／貝斯節奏，加入較疏的吉他點綴；尚未另製完整動作風格編排。
- 已移除原始節奏模式與選單。若來源已有 guitar 音軌仍保留該聲部；儲存的旋律與和弦資料不變。

這次保留原本的和弦選擇；自動配和弦仍是局部啟發式，沒有宣稱已完成專業和聲校對。取樣改善了聲音來源，但小三度跨音高移調、有限力度層與簡單伴奏型仍不同於真人演奏或大型專業音源。

## 木吉他更新驗證

吉他音符與原和弦音高類別一致，拍位與時值不超出原和弦區間；資料檔與旋律不變。新增測試涵蓋吉他預設音量、半拍撥弦、休止／結尾、現有吉他聲部保留、固定柔和編排與音軌控制。音色重建腳本支援 `--instrument nylon-guitar`，可在同一來源 SoundFont 下僅重建吉他，保留鋼琴／貝斯檔案。

Chromium 已驗證吉他獨奏的確有輸出，獨奏時鋼琴與貝斯增益為零。八首各前 10 秒的混音峰值仍約 0.36–0.62，沒有削波，瀏覽器無錯誤。《奇異恩典》新版約 21 秒比較檔已包含木吉他，仍為響度對齊的伴奏示範。上述為技術檢查，尚未經真人聆聽評分。

- 以瀏覽器實際音訊節點離線輸出八首各前 10 秒（含導奏，未含節拍器），峰值約 0.36–0.62，未削波；這是該段預設音量的檢查，不代表所有音量設定或全曲皆經檢測。
